## 包青天 2.1 Justice Bao 2.1 — 開封府金融偵探學院
股市英文 × 金融知識 × 推理闖關的教育遊戲網站，配上背景音樂〈汴京月夜清輝〉。

- **線上遊玩**：https://netaaron.github.io/bao_2_m/ （GitHub Pages：Settings → Pages，來源 `main` / `(root)`）
- **離線單檔版**：[`justice-bao-2.1-standalone.html`](justice-bao-2.1-standalone.html)（圖片與音樂已內嵌，下載後直接用瀏覽器打開）
- 這個 repo 的根目錄就是網站本身：`index.html`、`css/`、`js/`、`assets/`。本機測試時直接雙擊 `index.html` 即可，不需伺服器。
- 進度存在瀏覽器 localStorage；背景音樂在第一次點擊畫面後開始播放，右上角 ♪ 可開關。

## 3. 遊戲架構與計分
主線（完成前一關才解鎖下一關）：金融書齋 → 任務一 → 任務二 → 任務三 → 任務四 → 成績報告。主線滿分 700。

| 關卡 | 內容 | 計分 |
|---|---|---|
| 金融書齋 | 公孫策逐張教 9 觀念（英文、KK 音標、中文、英文定義、例句、翻譯、發音、相關概念），翻卡學習後做 3 題小測驗 | 每張 +5、每題 +15（90） |
| 任務一 案件與詞彙 | 阿明案情（可點字查詞、全文朗讀）、12 張翻轉單字卡、王朝抽考 4 題 | 每字 +5、每題 +10（100） |
| 任務二 配對特訓 | 兩回合各 6 組，計時；配錯顯示錯誤解析 | 每組 +10、連擊 3 組起每組 +5、配錯 −2、45 秒內 +10／75 秒內 +5（180） |
| 任務三 訊問與線索 | 8 條英文線索（★→★★★），展昭給線索、王朝整理卷宗；每題有中文輔助、解析、金融知識補充；可重練答錯題目（不計分） | 每題 +15、連續答對 3 題起每題 +5（150） |
| 任務四 斷案宣判 | 公堂案情與 4 件證物；四問（金融知識、英文理解、邏輯推理、風險意識複選）；三位顧問中選出最有紀律的計畫；判決動畫 | 每問 +30、決策第一次 +60／第二次 +30／第三次 +10（180） |

最終判決：五大面向（金融知識、英文理解、邏輯推理、風險意識、決策判斷）依整場對應題目答對率計算，平均 ≥85 金牌金融偵探、≥70 優秀見習偵探、≥50 繼續修習、其餘重新調查。
等級：見習偵探 0 → 初級偵探 150 → 金融分析師 350 → 投資策略師 550 → 資本市場大師 680。
成就：詞彙大師、金融偵探、調查專家、風險守護者、正義冠軍、開封名捕。
進階卷宗與金融工具：保留第一版全部功能（5 案、4 個試算實驗、終極大審、卷宗筆記），分數計入總分與等級，不影響主線判決。
